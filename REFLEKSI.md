\# Refleksi Teknis



\## Keputusan desain

Saya menggunakan Flutter sesuai arahan terbaru dosen. Data tugas disimpan di SQLite lokal melalui sqflite agar aplikasi dapat digunakan tanpa internet. Kode dipisahkan menjadi layar, pengelola state, repository, dan akses database supaya UI tidak langsung menjalankan query.



\## Kendala

Pada awalnya Flutter belum mendeteksi perangkat Android saat menjalankan aplikasi. Setelah perangkat Android siap, aplikasi dapat dijalankan dan APK berhasil dibuat.



\## Hal yang dipelajari

Saya mempelajari alur tambah, baca, edit, dan hapus data lokal, serta cara perubahan data memperbarui daftar tugas.



\## Perbaikan berikutnya

Saya ingin menambahkan pengujian otomatis dan meningkatkan tampilan filter agar jumlah tugas yang ditampilkan lebih jelas.
