Hasil Pengujian Aplikasi Tugas Mahasiswa

Aplikasi diuji pada HP Android. Data tugas disimpan secara lokal dengan SQLite. Bagian yang berstatus Belum diverifikasi perlu diuji dan diperbarui sesuai hasil sebenarnya sebelum pengumpulan.



1\. Menambah tugas

Langkah: Isi mata kuliah, judul, deskripsi, deadline, prioritas, dan status, kemudian tekan Simpan tugas.



Hasil: Tugas baru muncul pada halaman daftar.



Status: Berhasil.



2\. Melihat detail tugas

Langkah: Ketuk salah satu tugas pada halaman daftar.



Hasil: Halaman Detail Tugas menampilkan judul, mata kuliah, deskripsi, deadline, prioritas, dan status.



Status: Berhasil.



3\. Mengedit tugas

Langkah: Buka halaman Edit Tugas, ubah status dari Belum menjadi Proses, kemudian simpan.



Hasil: Status Proses muncul pada daftar tugas.



Status: Berhasil.



4\. Memfilter tugas berdasarkan status

Langkah: Pilih filter Proses di halaman daftar.



Hasil: Tugas berstatus Proses tetap terlihat pada daftar.



Status: Berhasil.



5\. Menampilkan data saat mode pesawat aktif

Langkah: Aktifkan mode pesawat, lalu buka halaman daftar tugas.



Hasil: Tugas yang sudah tersimpan tetap terlihat saat ikon mode pesawat aktif.



Status: Berhasil untuk menampilkan data saat mode pesawat aktif. Uji daya simpan setelah aplikasi ditutup dicatat terpisah pada nomor 6.



6\. Memastikan data tetap ada setelah aplikasi ditutup

Hasil: Setelah Wi-Fi dan data seluler dimatikan, aplikasi ditutup dan dibuka kembali, tugas yang tersimpan tetap muncul dengan status Proses.



Status: Berhasil.



7\. Menghapus tugas dengan konfirmasi

Hasil: Saat ikon hapus ditekan, dialog konfirmasi muncul. Memilih Batal membuat tugas tetap ada. Saat Hapus dipilih pada tugas uji, tugas hilang dari daftar.



Status: Berhasil.



Catatan

Jangan uninstall aplikasi saat menguji buka ulang, karena uninstall dapat menghapus database lokal aplikasi.

Mode pesawat tidak menjamin Wi-Fi mati jika Wi-Fi diaktifkan kembali secara manual; periksa Wi-Fi secara terpisah.

Empat screenshot utama tersedia di folder screenshots/: Daftar.png, Tambah.png, Detail.png, dan Edit.png.

Sebelum pengumpulan, lengkapi hasil nomor 6 dan 7 sesuai pengujian nyata serta ubah statusnya jika berhasil.
