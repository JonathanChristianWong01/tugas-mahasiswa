\# Hasil Pengujian Aplikasi



Pengujian dilakukan pada HP Android.



| Skenario | Hasil |

|---|---|

| Tambah tugas | Tugas baru muncul pada daftar. |

| Lihat detail | Mata kuliah, judul, deskripsi, deadline, prioritas, dan status tampil. |

| Edit tugas | Status diubah dari Belum menjadi Proses dan perubahan tampil pada daftar. |

| Filter status | Tugas berstatus Proses tampil saat filter Proses dipilih. |

| Hapus dengan konfirmasi | Isi setelah mencoba tombol hapus dan dialognya. |

| Offline | Isi setelah Wi-Fi dan data seluler mati, aplikasi ditutup, lalu dibuka ulang. |
